# Character Classes & Identity

## 1. Purpose

Character identity is built from four components:

Species
+ Prefix
+ Base Class
+ Suffix

Example:

Undead Pyromaniac Bastion
Of The Exploding Kneecaps

Each component contributes meaningful mechanics.

The combinator should create builds that feel substantially different rather than generating humorous names attached to tiny stat differences.

---

# 2. Species

Species defines fundamental biological or metaphysical rules.

Initial design pool:

## Human

Adaptable generalist.

Possible traits:
- Increased general XP
- Flexible starting attributes
- Additional profession flexibility

## Undead

Returned from death.

Possible traits:
- Poison immunity
- Reduced conventional healing
- Alternative interactions with Medicine
- Necrotic affinity

## Automaton

Constructed life.

Possible traits:
- No hunger
- Resistance to biological effects
- Repair-based recovery interactions
- Reduced effectiveness from conventional healing

## Fey-Touched

Partially altered by Realm influence.

Possible traits:
- Increased Mana
- Magical affinity
- Realm-event interactions
- Reduced physical resilience

## Beastkin

Predatory or animalistic lineage.

Possible traits:
- Tracking
- Movement
- Beast Lore synergy
- Enhanced senses

## Hollowborn

A person whose relationship with death has become questionable.

Possible traits:
- Fear resistance
- Death-related interactions
- Increased resistance while critically wounded
- Unusual Realm event options

## Stoneblood

Dense, mineral-like physiology.

Possible traits:
- High physical resistance
- Knockback resistance
- Slower movement/action baseline

## Ashborn

Descendants or survivors of volcanic Realms.

Possible traits:
- Fire resistance
- Heat affinity
- Cold vulnerability

## Deepkin

Adapted to darkness and underground environments.

Possible traits:
- Increased perception in darkness
- Improved subterranean gathering
- Light-related weaknesses or differences

## Veilborn

Touched by unstable boundaries between Realms.

Possible traits:
- Improved Wayfinding
- Strange portal interactions
- Increased susceptibility to certain magical effects

Final species balance remains subject to iteration.

# 3. Base Classes

Base Classes define the primary combat chassis.

IMPORTANT:

Use the project's custom fantasy class names rather than default RPG labels such as Fighter whenever possible.

The final historical class names from prior design work should be preserved when available.

Known preferred example:

## Bastion

Defensive martial chassis.

Identity:
- Armor
- Blocking
- Guarding
- Stamina
- Positional protection

Possible signature abilities:
- Brace
- Shield Wall
- Interpose
- Retaliatory Guard

Additional class names should follow this naming philosophy.

Working concepts until final names are established:

## Hexslinger

Mobile magical/ranged combat chassis.

## Wayfarer

Mobility and ranged positioning chassis.

## Pitfighter

Aggressive close-range martial chassis.

## Gravetender

Death / spirit manipulation chassis.

## Haruspex

Risk/reward occult caster.

## Warden

Control and protection chassis.

## Wretch

Survivalist / dirty-fighting chassis.

## Spellblade-Type Chassis

Hybrid weapon/magic role. Final project-specific name required.

## Summoner-Type Chassis

Companion/control role. Final project-specific name required.

Do not silently replace established class names if they already exist elsewhere in project design.

# 6. Suffix Philosophy

Suffixes are RULE BREAKERS.

A good suffix should make the player reconsider how they play.

Avoid filling the suffix pool with:

"+5% damage."

Those effects belong on ordinary items or progression.

Suffixes should create stories.

---

# 8. Unlocking Class Components

Long-term design should consider making Prefixes and Suffixes discoverable/unlockable.

Potential sources:

- Realm discoveries
- Bosses
- Profession milestones
- Class quests
- Rare events
- Realm Knowledge
- Achievements

This gives players combinations to hunt.

# 9. Build Philosophy

A build should create interactions between:

Class
Professions
Equipment
Realm
Player skill

Example:

Undead
Pyromaniac
Bastion
Of Improper Safety Procedures

may become an aggressive tank that intentionally creates hazardous fire zones while using defensive positioning to survive its own chaos.

That is more interesting than:

"+10 Strength."
